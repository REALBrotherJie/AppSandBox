# AppSandbox UI reusable kit

这套文档把 2026-09-23 完成的 Android 宿主 UI 经验抽象为可复用规范，适用于 AppSandbox 及其他普通 Android App。文档只保留设计方法、交互约束和验收标准，不复制其他项目的源码、类名、专有业务逻辑或虚拟化实现。

## 文档

- [UI 改造计划](./UI-PLAN.md)：从当前页面到个人应用空间的实施顺序、页面结构和验收标准。
- [设计令牌](./UI-TOKENS.md)：颜色、字体、间距、圆角、触控区域和无障碍规则。
- [AppSandbox 映射](./APPSANDBOX-MAPPING.md)：将规范映射到当前 APK 导入和 Guest 摘要页面。

## 使用原则

1. 先建立当前页面截图和构建基线，再逐个实现任务。
2. 先改宿主 UI，再改数据状态；不要把视觉换肤和容器引擎混在一个提交中。
3. 所有按钮都必须对应真实功能；没有实现的能力不显示为可点击入口。
4. 所有列表操作使用稳定业务身份，不依赖当前显示位置。
5. 保持 AppSandbox 的 clean-room 约束：实现依据来自 Android SDK、AOSP、官方文档和本地实验。
6. 每项完成后记录改动文件、验证设备、截图、测试结果和已知限制。

推荐第一批顺序：UI-00 → UI-01 → UI-02 → UI-03 → UI-04 → UI-05。对 AppSandbox 当前页面，UI-03 的首个目标是 APK 导入结果卡片，UI-04 的首个目标是失败重试和清空状态。
