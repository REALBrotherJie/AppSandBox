# UI 设计令牌

## 颜色

| 角色 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| background | `#F6F7FB` | `#111318` | 页面底色 |
| surface | `#FFFFFF` | `#1C2028` | 卡片和输入区域 |
| primary | `#315DA8` | `#ADC6FF` | 主按钮、选中态 |
| onPrimary | `#FFFFFF` | `#102F60` | 主按钮文字 |
| text | `#1A1C20` | `#E3E5EC` | 主文字 |
| textSecondary | `#555F70` | `#B6BECC` | 辅助文字 |
| outline | `#747D8C` | `#8892A3` | 输入框和边界 |
| error | `#BA1A1A` | `#FFB4AB` | 错误状态 |

## 尺寸

- 页面水平边距：20dp。
- 页面区块间距：8/12/16/24/32dp。
- 卡片圆角：16–20dp；弹窗圆角：24dp。
- 主按钮最小高度：56dp。
- 图标操作区：至少 48×48dp；图标本体通常 24dp。
- 应用图标：48–72dp，保持原始比例。
- 标题 26–28sp；区块标题 18sp；正文 16sp；辅助文字 12–14sp。

## 组件规则

- 卡片使用低阴影，依靠留白和颜色层级区分，不使用旧式厚重阴影。
- 长应用名最多两行省略；详情页显示完整名称。
- 列表搜索只改变可见集合，不改变业务对象身份。
- 状态颜色必须同时配合文字或图标，不能只靠颜色传达成功/失败。
- 图片和装饰图标设置为非重要无障碍元素；操作图标提供 contentDescription。
- 优先使用主题资源，不在 Kotlin/Java 中散落硬编码颜色。
- API 31+ 支持系统明暗模式；API 36 目标下处理 edge-to-edge Insets。

## 文案

推荐使用具体动作：

- “导入 APK”而不是“开始”。
- “重新选择”而不是“重试”当失败发生在文件选择阶段。
- “查看详情”而不是直接展示原始堆栈。
- “未提供”表示 APK 本身缺少字段；“读取失败”表示流程出错。
