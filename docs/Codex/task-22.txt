当前确认状态：

```text
ACT-001 Host Activity + Guest View = CONFIRMED on API31/API36
ACT-002 Guest Activity Java object construction = CONFIRMED on API31/API36
Guest Activity attached = NO
Guest lifecycle executed = NO
Manifest Stub carrier = NOT IMPLEMENTED
```

ACT-003 只验证：

```text

```

这里的 token/task/window 全部属于 Host Stub，不属于 Guest。


## 二、允许实现的最小 Stub

只允许新增一个 debug-only standard Activity，例如：

```text
app/src/debug/java/com/example/appsandbox/experiments/act003/Act003StubActivity.kt
```

并仅在 `app/src/debug/AndroidManifest.xml` 声明：

```text
android:exported=false
standard launchMode（默认或显式 standard）
Host debug theme
不设置 Guest taskAffinity
不设置 Guest package/process/theme/orientation
```

不要创建 standard/singleTop/singleTask 等 Stub 池；ACT-003 只验证一个 standard Host Stub。

Stub 页面使用 Host 资源或代码创建的简单 Host TextView marker。不得加载 Guest View，也不得实例化 Guest Activity。

## 三、启动链

通过现有 debug `ExperimentActivity` 增加 `mode=act003`，由它在应用内部启动非 exported 的 `Act003StubActivity`。

启动 Intent 只允许携带 Host-safe primitive 数据：

```text
launchId：随机或单调唯一字符串
logicalGuestPackage：com.example.appsandbox.testguest
logicalGuestComponent：GuestMainActivity
revisionId
```

不得放入 Guest Parcelable、Guest Bundle class、ActivityInfo、Binder token 或任意反序列化对象。

本轮不需要 production VirtualActivityRecord。可以使用 debug-only 简单数据或 Intent primitive extra。

## 四、Stub 必须记录的公开状态

`View.getWindowToken()` 可以用于验证公开可观察的非空 token，但：


window token 应在 decor 已 attach 后观察，例如 `decorView.post`、获得 window focus 后或其他公开生命周期点。不得因为 onCreate 过早返回 null 就使用 hidden API。

## 七、负向控制

至少包含：

### 1. Direct Guest launch

直接启动未安装 Guest Activity 仍必须被拒绝：

```text

```

### 2. Guest object absence

记录：

```text
GuestMainActivity constructionCount 未增加，或等价证据
Guest Activity object instantiated=false
```

注意：如读取 constructionCount 需要加载 Guest class，就会产生类加载副作用。优先使用 ACT-003 runner 本身没有调用 Guest loader/constructor 的代码和日志证据；不要为了证明未构造而额外构造或加载 Guest Activity。

### 3. Missing/invalid launchId

使用内部 debug 路径启动一次缺失或无效 launchId 的 Stub。Stub 必须 fail closed：

```text
不加载 Guest
不崩溃 Host process

finish()
```

不得允许外部 App 直接启动 Stub；`exported=false` 必须保持。

## 九、结果分类

只允许：

```text
ACT-003 = CONFIRMED
ACT-003 = PARTIALLY CONFIRMED
ACT-003 = REJECTED
```

`CONFIRMED` 条件：

```text
API31/API36 均正常启动 debug Manifest Stub。
系统/ADB 证据均显示 Host Stub component。
公开 decor windowToken 在 attach 后非空。
Host taskId/window/lifecycle 可观察。
Guest package 未安装，direct Guest launch 被拒绝。
没有实例化或 attach Guest Activity。
invalid launchId fail closed。
```

`PARTIALLY CONFIRMED`：仅一个 API 通过、token/window 观察不完整、dumpsys 证据缺失或设备不可用。

`REJECTED`：Stub 无法通过正常系统路径启动，或必须依赖本轮禁止的机制。

等级必须写：

```text
L0 CONFIRMED by ACT-001
L2 Java object construction observed by ACT-002
L3 NOT CONFIRMED；本轮只确认 Host Stub carrier baseline
L4 NOT TESTED
L5 NOT AVAILABLE
```
