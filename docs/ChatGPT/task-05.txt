# 三、不要再只使用 APK MIME 作为系统文件选择过滤条件

当前：

```text
application/vnd.android.package-archive
```

在不同：

* DocumentsProvider
* ROM
* Download provider
* File manager

上可能出现：

* MIME 识别差异
* `application/octet-stream`
* provider 不按 APK MIME 暴露
* DocumentsUI 过滤行为差异

因此需要调整：

# “选择阶段宽松，导入阶段严格验证”

而不是：

# “完全依赖 MIME 判断是不是 APK”。

---

# 四、调整 SAF 选择策略

继续使用：

# 五、不能因为使用 `*/*` 就允许任意文件导入

SAF 文件选择范围放宽后：

AppSandbox 自己必须严格验证文件。

建立导入验证顺序。

建议：

```text
URI selected
↓
读取 OpenableColumns.DISPLAY_NAME
↓
记录 ContentResolver.getType(uri)
↓
检查基础输入可读性
↓
复制到临时文件
↓
使用 Android PackageManager archive API 验证
↓
只有真正可解析为 APK 才进入 Guest Store
```

不要只依赖：

```text
filename.endsWith(".apk")
```

因为扩展名可以伪造。
