Guest Activity 获得：

* Window/token

* result
* task
* lifecycle
* configuration
* saved state
* window

## L5 — System-real Activity

真正被 PMS/ATMS 识别为 Guest package/component。

普通未安装 Guest 路线通常无法达到。

明确每一级。
