# 七、写入时序非常重要

不要简单采用：

```text

↓
close
↓
setReadOnly()
```

作为首选生产路径。

优先按 Android 官方建议设计：

```text
create destination/staging file
↓
open FileOutputStream
↓
immediately mark file read-only
↓

↓
write APK bytes through already-open FD
↓
flush / sync
↓
close
```

核心原则：

# 文件在内容写入前就移除可写权限。

在 Linux/Android 上：

已经打开的 FD 仍可以完成当前写入；

后续重新打开文件进行写操作应该失败。

必须实际验证。
