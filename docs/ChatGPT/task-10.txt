同一个 Guest Instance：

```text
onCreate
```

不能无意执行多次。

第一版定义：

```text
CREATED
ATTACHED
ON_CREATE_RUNNING
RUNNING
FAILED
DESTROYED?
```

不要实现复杂正式状态机。

但实验文档必须记录：

生命周期状态。

# 四十、Application 异常处理

如果 Guest：

```text
onCreate()
```

抛异常：

Host AppSandbox 不应该直接整个 crash。

设计：

```text
Guest Application failure
↓
捕获
↓

↓
记录 exception
```

Java `Error`

RuntimeException

LinkageError

不要简单：

```text

```

# 五十五、不能直接共享 Host interface class

注意 EXP-001 已确认：

Class identity 与 ClassLoader 绑定。

如果 Host 定义：

```text
Exp003ReportInterface
```

Guest 自己又打包一份同名 interface，

类型身份可能不同。

因此 EXP-003 设计：

优先使用跨 classloader 安全的数据：

* String
* primitive
* String Map
* Bundle（需要注意 classloader）
* JSON

不要直接 cast Guest custom object 为 Host custom interface。

这是 EXP-001 的直接架构结论。

---

给出推荐。
