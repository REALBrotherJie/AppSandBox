# 二十六、为什么 numeric ID 是核心路径

结果文档中明确记录：

正常编译后的 Guest Java/Kotlin 代码访问资源时：

```text
R.string.foo
```

已经在编译期转为资源 ID。

因此未来：

```text
Guest code
↓
R ID
↓
Guest Resources
```

是比：

```text
resource name
↓
getIdentifier()
```

更重要的主路径。

不要把 `getIdentifier()` 当成 EXP-002 的硬性成功条件。
