# 一、本轮核心问题

回答：

> 在仍然运行于 Host UID / Host Process 的现实条件下，是否可以构造一个受控的 Guest-facing Context，使 Guest 代码通过这个 Context 观察到正确的逻辑 package、Guest ClassLoader、Guest Resources、Guest APK path 和 Guest Instance storage，而不会通过核心 Context API 意外落回 Host application semantics？
